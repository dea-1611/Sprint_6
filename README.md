**Автотесты для сервиса заказа самокатов**
Этот проект содержит автотесты для проверки функциональности сервиса заказа самокатов. Тесты написаны на Python с использованием Selenium, Pytest и Allure для отчетности.

**Основные тестовые сценарии**

1. Тестирование раздела "Вопросы о важном"
Проверка отображения правильного ответа при клике на каждый вопрос
Тестирование 8 вопросов в разделе FAQ

2. Позитивный сценарий заказа самоката
Проверка оформления заказа через верхнюю кнопку "Заказать"
Проверка оформления заказа через нижнюю кнопку "Заказать"
Тестирование с двумя разными наборами данных пользователей
Проверка появления всплывающего окна об успешном заказе

3. Проверка переходов по логотипам
Клик по логотипу "Самокат" - переход на главную страницу
Клик по логотипу "Яндекс" - открытие главной страницы Дзена в новой вкладке

**Технологический стек**
Python (версия 3.9+)
Selenium - для автоматизации браузера
Pytest - фреймворк для тестирования
Allure - система отчетов
Git - система контроля версий
